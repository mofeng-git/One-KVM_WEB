# 引导页

首次访问 One-KVM 时，系统会显示引导页面，帮助您完成初始配置。

## 欢迎页面

引导流程的第一步是欢迎页面，介绍 One-KVM 的主要功能和接下来的配置步骤。

## 配置步骤

### 1. 创建管理员账户

首先需要创建管理员账户：

- **用户名** - 登录用的用户名
- **密码** - 设置安全的密码
- **确认密码** - 再次输入密码确认

!!! tip "密码建议"
    建议使用至少 8 位字符的强密码，包含大小写字母、数字和特殊字符。

![onboarding-2026-01-03-22-14-23](images/onboarding-2026-01-03-22-14-23.png)

### 2. 音视频设备配置

- 选择视频采集设备
- 选择视频采集设备输入的画面格式
- 设置初始分辨率帧率
- 选择音频设备
- 选择编码器（可选）

![onboarding-2026-01-03-22-17-55](images/onboarding-2026-01-03-22-17-55.png)

### 3. HID 设备配置

- 选择 HID 后端
- 选择和设置设置 HID 后端设备及参数

![onboarding-2026-01-03-22-20-47](images/onboarding-2026-01-03-22-20-47.png)

### 4. 扩展设置

- 选择需要自动启动的扩展

![onboarding-2026-01-03-22-22-38](images/onboarding-2026-01-03-22-22-38.png)    

## 完成设置

确认所有配置无误后，点击"完成"按钮，系统将保存配置到数据库， 初始化各个硬件模块，自动登录并跳转到 KVM 控制台页面。

完成引导后，所有配置会立即生效。如需修改，可以在[设置页面](settings.md)进行调整。如果需要重新运行引导流程，可以删除数据库文件，然后重新启动程序。
