# 飞牛 MAS 安装

本文介绍如何使用直接在飞牛 NAS 系统上安装 One-KVM。

## 前提条件

- 系统要求：飞牛 NAS 系统，支持 X86_64 与 ARM 架构
- 硬件准备：插好 CH340+CH9329 HID 线（用于 HID 模拟），插好 USB HDMI 采集卡。

## 安装软件

### 应用市场安装

软件已经上架飞牛应用商店，可以直接安装。

![fnnas-install-2026-01-27-22-37-38](images/fnnas-install-2026-01-27-22-37-38.png)

### 手动安装

下载飞牛软件包（文件名后缀为 fpk）到文件系统上，然后在飞牛应用商店进行手动安装。

![fnnas-install-2026-01-20-15-35-14](images/fnnas-install-2026-01-20-15-35-14.png)

![fnnas-install-2026-01-20-15-36-02](images/fnnas-install-2026-01-20-15-36-02.png)

## 访问 Web 界面

打开浏览器访问 `http://<设备IP>:8420`

!!! tip "首次访问"
    首次访问时，系统会引导您完成初始配置，包括创建管理员账户。

## 更新软件

One-KVM 飞牛应用是基于 docker。所以更新应用可以在飞牛应用市场卸载One-KVM，然后在安装一次，就是最新版本了，默认情况不会丢失数据。
