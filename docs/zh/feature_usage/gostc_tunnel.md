# GOSTC 内网穿透

GOSTC 是基于 FRP 的内网穿透服务，One-KVM 内置客户端，可通过网页完成配置。需要系统内已安装 `gostc`（扩展页面显示“可用”），在 GOSTC 服务网站注册并获取客户端密钥。

!!! tip "服务网站"
    - One-KVM 专用（作者自建，需要验证邮箱）：`https://gostc.mofeng.run`
    - GOSTC 官方服务：`https://gost.sian.one/`

!!! warning "使用须知"
     内网穿透服务免费提供，仅供个人学习、测试及非商业用途使用，严禁进行长时间刷流量、批量注册、网络攻击、爬取他人数据、传播违法不良信息或任何商业盈利行为。<br>请合理使用资源，避免滥用导致服务中断，共同维护公平、健康的使用环境。

## 配置项

| 项目 | 说明 | 示例/默认 |
| --- | --- | --- |
| 服务器地址 | GOSTC 服务域名或 IP（不需要 http/https） | `gostc.mofeng.run` |
| 客户端密钥 | 在服务网站为设备生成 | - |
| 启用 TLS | 服务端支持时建议开启 | 开 |
| 开机自启 | 启动后自动运行 | 关 |

## 配置步骤

1. 在服务网站注册并登录，完成邮箱验证，之后在服务网站创建客户端并复制密钥
2. 打开 设置 → 扩展 → 远程访问 → GOSTC
3. 填入服务器地址、密钥，确认 TLS 选项
4. 点击 **保存**，再点击 **启动**

    ![gostc_tunnel-2026-01-28-00-25-54](images/gostc_tunnel-2026-01-28-00-25-54.png)
    连接密钥是客户端密钥，不是节点密钥。
    ![gostc_tunnel-2026-01-28-00-26-55](images/gostc_tunnel-2026-01-28-00-26-55.png)
    ![gostc_tunnel-2026-01-28-00-28-12](images/gostc_tunnel-2026-01-28-00-28-12.png)

## 在服务网站添加端口转发

1. 点击左侧隧道管理菜单，进入端口转发页面，然后新建端口转发隧道

    ![gostc_tunnel-2026-01-28-00-37-21](images/gostc_tunnel-2026-01-28-00-37-21.png)

2. 选择好节点、套餐和客户端

    ![gostc_tunnel-2026-01-28-00-32-07](images/gostc_tunnel-2026-01-28-00-32-07.png)

3. 输入内网配置

    服务名称随意，内网地址填写 `127.0.0.1`，端口填写 One-KVM 网页端口（通常是8080），其他选项可以使用默认的。如果需要更低延迟，可以关闭加密和压缩。

    ![gostc_tunnel-2026-01-28-00-36-01](images/gostc_tunnel-2026-01-28-00-36-01.png)

4. 然后点击保存，就可以看到远程访问地址了

    ![gostc_tunnel-2026-01-28-00-39-22](images/gostc_tunnel-2026-01-28-00-39-22.png)
