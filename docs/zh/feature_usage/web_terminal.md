# 网页终端（Ttyd）

通过 ttyd 在浏览器中访问 One-KVM 设备的命令行，适合快速查看日志、执行维护命令。

## 使用

系统内已有 `ttyd` 程序（扩展页面显示“可用”），且用户已登录。

- 控制台页面右上角工具栏 → 扩展 → Ttyd 网页终端
- 设置 → 扩展 → Ttyd 网页终端 → 打开终端

如果提示未找到 `/usr/bin/ttyd`，可能系统里没有 ttyd 程序或者程序路径不对，需要自行安装。
