### GOSTC

!!! note "什么是 GOSTC?"
    GOSTC v2是基于开源项目FRP开发的内网穿透，通过WEB管理穿透服务，在外也能随时修改穿透配置，上手难度极低，支持多平台

    任何人只要你有云服务器，皆可自建节点服务，穿透的服务的体验完全取决与自己服务器的速率、带宽、延迟

该项目分为开源版本和 pro 版本，本项目使用的为开源版。

GOSTC 项目地址：https://docs.sian.one/gostc/info/

整合包和 Docker 镜像251001 以后的版本都预装了 GOSTC 服务，在登录 One-KVM 首页后可以看到 GOTSC 服务，点击即可进入设置网页。

### 使用方法

全程在网页操作，无需编写配置文件。GOETC 内网穿透软件的操作都是在 GOSTC 服务网站进行的，客户顿只需要添加秘钥，之后会自动实时地同步和应用你在服务网站设置的配置。

首先是服务网站,下面两个网站都是完全免费的。

!!! tip "提示"
    内网穿透服务免费提供，仅供个人学习、测试及非商业用途使用，严禁进行长时间刷流量、批量注册、网络攻击、爬取他人数据、传播违法不良信息或任何商业盈利行为。<br>请合理使用资源，避免滥用导致服务中断，共同维护公平、健康的使用环境。

=== "One-KVM 专用（作者自建）"
    针对 One-KVM 用途进行了优化，只接受 One-KVM 服务，不接受其他应用的内网穿透服务（避免滥用）。

    [https://gostc.mofeng.run](https://gostc.mofeng.run)

    ![alt text](../../img/image-251001085700000.png)

=== "GOSTC 官方服务网站"
    GOSTC 官方服务网站，无限制，延迟相对较高。

    [https://gost.sian.one/](https://gost.sian.one/)

    ![alt text](../../img/image-250901085900000.png)

在服务网站注册之后，首先添加客户端设备，名称自定义，点击保存，然后将点击链接秘钥并复制秘钥。接下来将秘钥和服务器地址（没有 http:// 或 https:// 前缀）填入 One-KVM GOSTC 网页。One-KVM GOSTC 网页新增客户端时建议启动自启动，这样设备重启后也会自动进行内网穿透。

![alt text](../../img/image-251001090200000.png)

![alt text](../../img/image-251001090600000.png)

客户端设备设备添加之后，手动打开开关，就会连接到服务器，此时你就可以在服务网站看到客户端上线了。

客户端设备设备添加好之后，就是添加隧道了。在服务网站端口转发页面新增端口转发，节点根据自己的情况选择，名称自定义，内网地址填写 `127.0.0.1`，内网端口一般填写 `443`（如果是 docker 部署填写 `4430`），点击保存，然后就可以看到外网访问的地址了。

![alt text](../../img/image-251001091200000.png)

![alt text](../../img/image-251001092000000.png)

之后有什么修改（比如更换端口、更换节点、增加节点）都可以在服务网站上修改，One-KVM GOSTC 客户端会自动拉取配置应用。


### 进阶使用

你也可以根据文档加入你自己的中转节点，或者建立你自己的服务端，使用方式非常灵活。
