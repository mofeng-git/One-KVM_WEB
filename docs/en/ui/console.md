### Video Control

One-KVM supports two video stream modes:

=== "WebRTC Mode"

    - H.264/H.265/VP8/VP9 encoding with low bandwidth usage
    - Requires a modern browser

=== "MJPEG Mode"

    - Better compatibility

### Mouse and Keyboard Control

One-KVM supports two mouse modes:

=== "Absolute Mode"

    - Mouse position maps directly to the target screen; no mouse capture needed
    - Recommended for GUI environments

=== "Relative Mode"

    - Sends relative mouse movement; requires mouse capture
    - For systems without absolute mouse support (e.g., Android)
